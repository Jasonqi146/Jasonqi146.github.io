I contributed to an open-source FLAN-T5 effort focused on instruction-following in Chinese and other multilingual settings. The work centered on broadening language coverage and making the data and prompting pipeline reproducible enough for others to build on.

My main contribution was expanding the project with more than 20 pipelines for multilingual instruction data creation, cleaning, and formatting. That meant thinking carefully about data shape, template consistency, and how to keep the system useful across languages instead of overfitting to one benchmark or prompt style.

This project was an early version of a problem I still like: building the machinery around a model, not just the model itself.
